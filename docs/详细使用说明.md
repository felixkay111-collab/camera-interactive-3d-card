# 详细使用说明与常见问题

[返回首页](../README.md)

## 直接在网页里编辑

“准备回忆”分为三个页签。点击 **保存这份心意** 后立即生效，刷新和重启后也会保留；点击 **取消修改** 或关闭编辑窗口会放弃本次未保存的内容修改。

### 文字与字幕

- 修改页面标题、开场标题、结尾标题和结尾正文。
- 按“开场、手势练习、蛋糕与花束、回忆与信件、结尾、手势提示”展开各组文字。
- 支持修改中文标题、英文小字、装饰卡片文字、信封和信纸称呼、开始/重播等展示按钮、手势提示。
- 文本框里按回车即可换行；字幕留空会显示为空，不会被默认文字覆盖。
- 回忆数量说明中的 `{count}` 自动显示总数；素材准备提示中的 `{ready}` 显示已替换的素材数。保留这两个占位符即可自动更新，也可以改成普通句子。
- 信封称呼和信纸称呼可以分别编辑。页面中的系统报错、编辑器标签和工具栏图标属于操作界面。

### 照片与视频

回忆数量为 **1–50 项**，每一项都可以是照片、GIF 或视频，没有固定的“第八项”。

| 操作 | 方法 |
| --- | --- |
| 批量添加 | 点击“添加照片 / 视频”，可同时选择不同类型的文件，按文件名排序后追加 |
| 替换单项 | 点击该行“替换”，照片可以换视频，视频也可以换照片 |
| 调整顺序 | 使用每行的 ↑ / ↓ |
| 删除 | 点击该行“删除”，或用“清空列表”重新准备 |
| 添加占位 | 点击“添加空白回忆”，创建一项可替换的演示画面 |
| 修改字幕 | 直接编辑素材旁的说明，留空则不显示字幕 |

格式：JPG、PNG、WebP、GIF、MP4、WebM。MP4 推荐 H.264 编码；HEIC/Live Photo 请先导出为照片、GIF 或视频。单张静态照片最大 35 MB，GIF/视频最大 60 MB。

默认演示素材可直接删除。添加文件会追加到现有列表；想从头开始，先清空列表再导入。空列表可以继续编辑，但保存前至少需要一项。

图片完整显示，相框根据素材的实际横竖比例自动调整。视频静音播放，每次循环间隔 1.5 秒；GIF 按文件自带的动画时序播放。页码和信封星环会随数量更新。结尾最多抽取 12 项组成回忆拼贴，视频以静态预览显示，避免大量视频同时解码。

### 信件与音乐

- 直接输入信件或导入 TXT，保留换行和段落，长信自动分页。可留空，最多 30,000 字。
- 默认附带舒缓梦幻的原创合成纯音乐，也可替换为 MP3 / WAV / M4A / OGG（最大 60 MB）。
- 右上角可调音量、静音和全屏。

## 手势与现场控制

- 握起手掌：蛋糕/花束的星光聚拢；张开：星光散开。
- 左右移动手掌：转动星光形状，回忆阶段让画面轻微倾斜。
- 比 OK 手势并松开：进入下一步或翻页。必须松开后才能再次触发。
- 信封阶段张开手掌约一秒：打开信。
- 按钮和键盘 `←` / `→` / 空格：手动切换；`C` 重试摄像头，`M` 切换音乐，`S` 打开编辑器。

摄像头画面仅在浏览器本地处理，不上传、不录制。手离开后会停留在当前场景。建议提前用实际摄像头彩排。

## 保存与备份

- 保存后的文字、顺序和信件在 `app/content.json`，导入文件在 `app/media/`。
- 想把贺卡搬到另一台电脑，复制整个项目文件夹即可；把 runtime 文件夹一起复制即可，无需安装 Node.js。
- 点击删除或取消编辑，不会删除原始照片，也不会自动删除已经复制到项目内的素材。
- 提前用实际摄像头彩排，确认手势、音乐和照片顺序。

## 常见问题

### 启动提示运行工具缺失

请重新下载完整项目，完整解压后再启动。runtime 文件夹里应包含 node.exe。不要把“启动.bat”单独移走。本版本适用于 Windows 10/11 x64。

### 下载后打不开，或者启动窗口一闪而过

先右键 ZIP 压缩包，选择“全部解压缩”，再进入解压后的文件夹启动。请保留完整文件夹，不要把“启动.bat”单独拿到桌面，也不要直接打开 app 内的 index.html。

### 网页没有自动打开

看看启动窗口里显示的网址，用 Edge 或 Chrome 打开它。常见地址是 http://localhost:8787；如果端口已占用，显示的数字可能不同，请以窗口为准。

### 摄像头不工作

在浏览器地址栏的站点权限中允许摄像头，关闭正在使用摄像头的其他程序，然后按键盘 C 重试。让手掌处在明亮、清晰的位置。如果仍不方便，可用屏幕箭头或键盘左右键完成体验。

### 没有声音或不能全屏

点击右上角音乐按钮，检查音量；全屏可点右上角全屏按钮或按 F11。浏览器通常需要先点击一次页面，才允许播放声音。

### 某个视频打不开

使用 MP4（推荐 H.264 编码）或 WebM。手机导出的 HEIC / Live Photo 需要先转换成照片、GIF 或可播放的视频，再导入。

### 删除到没有照片后不能保存

至少保留一段回忆。可以添加照片或视频，也可以点击“添加空白回忆”放入演示画面。

### 关闭后再开，修改还在吗？

点击过“保存这份心意”的内容会保留。直接关闭编辑窗口只会放弃这次未保存的修改。备份时复制整个项目文件夹，避免遗漏保存的配置或素材。
