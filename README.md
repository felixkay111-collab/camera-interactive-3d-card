# 摄像头交互式3D贺卡

用手势让星光变成蛋糕和花束，再翻开照片、视频和一封信。文字和素材都能在网页里直接修改。

## 怎么打开？

适用于 **Windows 10/11 的 64 位电脑（x64）**，使用 Edge 或 Chrome 浏览器。**附带运行工具，下载后可在本地直接运行。**

1. **Download ZIP** 下载并解压完整文件夹。
2. 双击项目中的 **启动.bat**，网页会自动打开。使用期间保留power shell启动窗口。
3. 编辑方式：点击网页右上角 **准备回忆**，修改后点击 **保存这份心意**。
4. 预览/播放：点击 **开启这份惊喜**，允许使用摄像头。也可以先用鼠标彩排。

## 怎么互动？

- **握拳 / 张开手掌**：星光聚拢成蛋糕或花束 / 散开。
- **比 OK 手势，再松开**：切换下一步。
- **在信封前张开手掌一秒**：打开信件。
- 屏幕箭头或键盘左右键也能操作。

本项目解压后可以断网使用，摄像头画面只在本机处理。请保留完整文件夹，包括 runtime 运行工具。
